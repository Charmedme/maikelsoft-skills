# Brief: hello

Status: approved (G1, 2026-09-01)

## Need
New colleagues get a greeting in their own language.

## Output
One line. A file `greeting.txt` when the user asks for a file, else the reply.

## Success criteria
- The greeting is in the language of the request (Dutch request: Dutch greeting).
- The greeting is one line.
- The skill asks no questions.
- With no language signal, the greeting is in English.
