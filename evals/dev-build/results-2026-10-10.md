# Results 2026-10-10

Method: see `evals.json` and `evals-agent.json`. One separate agent (Sonnet) for each run. 3 runs for each variant. Baseline is an agent with no skill. 

A script scored the `check` assertions. One grader agent scored the `judge` assertions of each eval. The grader could see the variant name in the path.

## Limits of these tests

- The graders saw the variant name in the path.
- Rule-ID citations favour the skill, because the IDs are in the skill.
- Nobody ran an agent that the skills built on real work. No sub-agent was available to the runs.
- The trigger test used a placeholder description for `build-agent`, and easy queries.
- The two baseline review runs could not save a report file (the tool refused). The orchestrator saved their findings from the final message.
- The OpenClaw reference is not complete for `tools`, `sandbox`, and `bindings`.
