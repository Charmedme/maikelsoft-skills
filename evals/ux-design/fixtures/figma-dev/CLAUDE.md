# Fieldline

Web app for planners of service technicians. See `PRODUCT.md` for the product and `DESIGN.md` for the design system.

## Design

- Design tools: Figma (Professional plan, Dev seat)
- Mockup tool: html
- Figma files: https://www.figma.com/design/FAKE31/Fieldline?node-id=0-1
- Design-system source: design-system/tokens.css, design-system/components.css, DESIGN.md
- Brand files: DESIGN.md, PRODUCT.md
- UI stack: plain HTML and CSS screens in `screens/` (prototype phase of the product)
- Languages: en
- Run the app: open the files in `screens/` in a browser
- Playwright: installed (Python)
