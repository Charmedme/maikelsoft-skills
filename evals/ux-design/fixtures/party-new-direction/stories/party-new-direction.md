# NDK-12 Nieuw ontwerp: wachtkamer en spelscherm

As a player, I want a lobby and a game screen that feel like a party, so that the game starts the evening with energy.

Request of the owner (product owner, 2026-10-27):

> "Maak 3 concepten voor de wachtkamer (lobby) en het spelscherm. Kies een totaal nieuwe aanpak. Het huidige Gameshow-uiterlijk voelt oud en saai: paarse vlakken, witte kaarten, de Bungee-letter. Ik wil iets dat echt anders is, niet een bijgewerkte versie van wat er nu staat."

## Acceptance criteria

- AC-1: The lobby shows the sessiecode and a QR code, so that players can join.
- AC-2: The lobby shows each player that joined. The host sees the doelscore (5, 7, or 10) and "Start het spel" (at least 3 players).
- AC-3: The game screen shows the stelling, the hand of 7 cards, the ronde, and the leider.
- AC-4: Each player can switch music, chat, and microphone on and off from the lobby and the game screen.
- AC-5: Each player can leave the game from the lobby and the game screen.
