# NDK-14 Wachtkamer en stand: bediening tijdens het spel

As a player, I want to set music, chat, and microphone, see who plays, and see the stand, so that I can play the game the way my group likes.

## Acceptance criteria

- AC-1: The lobby shows the sessiecode, the players that joined, and the own name. A player can change the own name.
- AC-2: The host sets the doelscore (5, 7, or 10). The host can remove a player from the lobby.
- AC-3: Each player can switch music, chat, and microphone on and off in the lobby. Music stays switchable on the stand.
- AC-4: The stand shows each player with the points, sorted on points. A player can switch the game sounds off and on from the stand.
- AC-5: A player can leave the game from the lobby and from the stand.
