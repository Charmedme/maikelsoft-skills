# Naar de Kloten

Party card game for 3 to 10 players in one room or on a video call. Each player uses the own phone. See `PRODUCT.md` for the product.

## Design

- Design tools: none
- Mockup tool: html
- Design-system source: design-system/gameshow/tokens.css, design-system/gameshow/components.css (the "Gameshow" foundation)
- Brand files: PRODUCT.md (no DESIGN.md yet)
- UI stack: Angular 20, standalone components, signals, plain CSS with the Gameshow tokens. Templates in `src/app/<screen>/`.
- Languages: nl
- Run the app: `npm start` (ng serve, port 4200). Not available in this checkout: open the mockups in a browser.
- Playwright: installed (Python)
