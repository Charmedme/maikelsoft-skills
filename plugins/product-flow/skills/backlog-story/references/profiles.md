# Profiles

A profile sets the names and the extra fields. The rules of `story-rules.md` stay the same in each profile.

## Contents

- Select the profile
- Agile
- Scrum
- SAFe

## Select the profile

Use the profile that the human states. Else, use the signals: the names in the templates, the ticket system, or the existing items. With no signal, use Agile.

## Agile

- **Type:** User Story.
- Levels: Epic, Feature, User Story. The default is 2 levels: Feature or Epic, then User Story. Use 3 levels only when the human asks for it.

## Scrum

- **Type:** Product Backlog Item. The sentence and the criteria stay the same.
- Scrum has a product goal for the product and a sprint goal for each sprint. Refer to the product goal in "Notes" when one exists.

## SAFe

- **Type:** Story. Use "Enabler" for enabler stories.
- A story fits in one iteration.
- The parent is a Feature. Feature and Epic have a hypothesis and an outcome. The story does not.
